# Warband Script Enhancer 2 (WSE2)

WSE2 is a reimplementation and extension of the Mount & Blade: Warband game engine. It replaces the game executable with an enhanced version that adds hundreds of new scripting operations, triggers, Lua scripting support, and various engine improvements.
